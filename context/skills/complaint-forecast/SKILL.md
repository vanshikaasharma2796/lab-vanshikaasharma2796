# Complaint forecast

A store on benchmark draws about 3 wait-time complaints per 10,000 drive-thru orders.

Once a store is more than 5 seconds over benchmark, add 0.55 per 10,000 for every second over.

Complaints follow drive-thru time within the same week, so a fix in the kitchen shows in the queue almost at once.
